DeadOxide in the browser preview

The same Rust engine as the desktop client, compiled to WebAssembly. It needs your own copy of Project Zomboid 42.21.0: nothing from the game is hosted here, and the files you pick stay on your computer (they are read in this tab and never uploaded).

  • Pick the folder that contains media (Steam: right-click the game, Manage, Browse local files; on macOS pick Project Zomboid.app/Contents/Java).
  • The browser will list the whole folder; only about 420 MB of it is read (tile packs, tile definitions, scripts, cell headers, one map cell). Needs a desktop browser with WebGL2 and about 2 GB of free memory.
  • What you get: the Rosewood start house and its 256x256 cell, walking with the ported collision (walls, closed doors, windows). No zombies, items, lighting, sound or interface yet.
